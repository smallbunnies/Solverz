# Solverz brand artwork

These PNG assets implement the Solverz geometric sun identity. Keep the sun, polygon arrangement, spelling, and color order consistent across project materials.

| File | Dimensions | Use |
| --- | --- | --- |
| [logo-horizontal-light.png](logo-horizontal-light.png) | 1774 × 887 | Headers on light backgrounds |
| [logo-horizontal-dark.png](logo-horizontal-dark.png) | 1774 × 887 | Headers on dark backgrounds |
| [logo-stacked.png](logo-stacked.png) | 1254 × 1254 | Narrow layouts and title pages |
| [symbol-square.png](symbol-square.png) | 1254 × 1254 | Organization avatar and project symbol |
| [logo-monochrome.png](logo-monochrome.png) | 1774 × 887 | Single-color layouts |
| [docs-banner.png](docs-banner.png) | 2172 × 724 | Documentation and tutorial introductions |
| [social-cover.png](social-cover.png) | 1774 × 887 | Repository social preview |
| [palette.json](palette.json) | JSON | Reference colors |

The first three letters, Sol, are orange. The remaining letters are deep blue on light backgrounds and light on dark backgrounds. All letters retain the same size and weight.

Scale each image proportionally. Retain its padding. The PNG files contain their backgrounds. The square symbol is reused for the website icon rather than maintaining a separate design.

The social cover has a 2:1 aspect ratio and is smaller than 1 MB, matching [GitHub's social preview requirements](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

The artwork was created with imagegen and selected for Solverz. Website colors and layout are implemented in `docs/src/conf.py` and `docs/src/_static/custom.css`.
