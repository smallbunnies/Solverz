# Brand assets

## Keep the identity consistent

Scale artwork proportionally and retain the space around the sun. Keep the polygon arrangement, orientation, and color order intact. Use the complete spelling Solverz without a space or a change in letter size between Sol and verz.

The PNG files include their light or dark background. Choose a version that suits the surrounding page. Use the monochrome version when the layout requires one ink color.

The square symbol also serves as the website icon. It uses the same artwork as the project avatar.
